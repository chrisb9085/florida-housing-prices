# Florida Housing Prices

This project uses a neural network trained on the **FHFA House Price Index (HPI)** to predict next month’s housing price index based on data from the previous year.

## Overview
- Predicts future housing prices in Florida using historical HPI data.
- Designed as a machine learning project focused on time-series forecasting.

## Tech Stack
- Python
- NumPy
- Pandas
- Jupyter Notebooks
